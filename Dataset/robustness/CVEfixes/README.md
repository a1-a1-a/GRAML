# CVEfixes Robustness Split

This folder contains robustness variants derived from the `CVEfixes` evaluation set.

## Files

- `CVEfixes_noise.json`
- `CVEfixes_obfuscate.json`
- `CVEfixes_structure.json`

## Use Case

Use these files to measure how model predictions change when the same underlying `CVEfixes` examples are perturbed with different robustness transformations.
