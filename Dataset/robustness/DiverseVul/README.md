# DiverseVul Robustness Split

This folder contains robustness variants derived from the `DiverseVul` evaluation set.

## Files

- `DiverseVul_noise.json`
- `DiverseVul_obfuscate.json`
- `DiverseVul_structure.json`

## Use Case

Use these files to test whether predictions remain stable on perturbed `DiverseVul` examples.
