# PrimeVul Robustness Split

This folder contains robustness variants derived from the `PrimeVul` evaluation set.

## Files

- `PrimeVul_noise.json`
- `PrimeVul_obfuscate.json`
- `PrimeVul_structure.json`

## Use Case

Use these files to assess whether predictions remain stable on transformed `PrimeVul` examples.
