# Ultimate Test Robustness Split

This folder contains robustness variants derived from the GRAML in-distribution test set `Ultimate_test`.

## Files

- `Ultimate_test_noise.json`
- `Ultimate_test_obfuscate.json`
- `Ultimate_test_structure.json`

## Use Case

Use these files when you want to evaluate robustness on the main GRAML test set itself, rather than on external datasets.
